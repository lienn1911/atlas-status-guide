2. Automated UK SMS and API

Confirmed by Aircall
Workspace supports manual one-to-one SMS.
List-based automation uses an integration or the Messaging API.
Direct API access requires Professional.
UK SMS requires an eligible UK mobile number for domestic messaging.
Native mode supports replies in Workspace.
The API documents send, receive and status webhooks, a shared limit of 60 requests per minute, and separate number limits.

4. Plan and UK pricing

Published pricing
Essentials supports AI CSV campaigns. Annual pricing starts at £25 per seat per month, with a three-seat minimum (£75 per month equivalent).
Professional supports direct Messaging API access. Annual pricing starts at £40 per seat per month, with a three-seat minimum (£120 per month equivalent).
Aircall documents 50 included AI minutes per month and £0.011 per outbound attempt, including unanswered attempts and retries. Published AI overage figures differ, so use the applicable written rate.
UK outbound SMS is charged per billable segment. The public pricing page directs customers to Aircall for rates.
