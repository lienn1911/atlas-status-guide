AI Calls

Can we upload Excel for AI calling?Yes. Export Excel as CSV, upload it in Aircall Dashboard and map columns to the AI script. Source
Can we pause AI calls?Admins and supervisors can pause campaigns. Source
What can we export?Call History exports outcomes, phone numbers and Call IDs. Source

SMS and API

Excel or CSV → our sending tool → Aircall Messaging API → delivery updates and Workspace replies.

Can Workspace send SMS from a CSV?Workspace offers manual one-to-one texting. List-based automation uses an integration or the Messaging API. Source
Which UK number can send SMS?An eligible UK mobile number can send domestic SMS. Source
Can staff see replies in Workspace?Native mode keeps replies in Workspace. Webhooks report sending, replies and status updates. Source
Which plan lets us send SMS from our own tool?Professional provides direct Messaging API access. Source
What are the SMS API limits?60 requests per minute across the Messaging API, plus separate limits per number. Source

Usage Charges

What is the base subscription cost?Annual billing equivalent for three seats: Essentials £75/month and Professional £120/month. Source
How many AI minutes are included?50 minutes per month. Source
What does each outbound attempt cost?£0.011 per attempt, including unanswered calls and retries. AI minutes are billed separately. Source
How is UK SMS billed?Per billable segment. Rates depend on the contract and destination. Aircall reports inbound and outbound usage separately. Confirm outbound rates, reply charges and two-way fees. SMS billing details Source

Monthly budget = subscription + billable AI minutes above the included allowance + outbound attempts × £0.011 + SMS segments × the quoted UK rate + applicable number and telephony charges.

Use the applicable written quote for AI overage and UK SMS rates.
