OptimoRoute

Tracking statusMeaningHow Atlas decides
UnscheduledDelivery arrangements are still unconfirmed or there is insufficient information to confirm them.
  1. Check Own van Routine first. use any active Scheduled or Failed override.
  2. Otherwise check OptimoRoute for unscheduled. A missing order alone is insufficient.
  3. If there is no applicable result, OW J is W, K, H, I, A, U, Y, UNSCHEDULED, blank or unmapped.
UnassignedThe order is on hold and has no assigned delivery arrangement.
  1. Check OW method T. ON HOLD - TBC gives Unassigned.
ScheduledThe delivery is being prepared, arranged or transported before the final delivery stage.
  1. Check Own van Routine first. #FFFFFF with an order number or #FFC000 gives Scheduled.
  2. Check OptimoRoute for a recognised status. If the result is unknown, continue to OW.
  3. If there is no applicable result, OW J is P, S or SCHEDULED.
Out for DeliveryAtlas includes scheduled Own van orders, drivers en route and drivers servicing the stop.
  1. Check Own van Routine first. use any active Scheduled or Failed override.
  2. Otherwise check OptimoRoute for scheduled, on_route or servicing.
  3. If there is no applicable result, OW J is OUT FOR DELIVERY.
DeliveredDelivery is confirmed by carrier evidence or an eligible Own van fallback.
  1. Check Own van Routine first. use any active Scheduled or Failed override.
  2. Otherwise check OptimoRoute for success.
  3. If there is no applicable result, OW J is C, DELIVERED, COMPLETE or COMPLETED.
FailedA delivery exception requires follow-up, such as an unsuccessful attempt or damage.
  1. Check Own van Routine first. #FFFF00 gives Failed.
  2. Otherwise check OptimoRoute for failed.
  3. If there is no applicable result, OW J is FAILED DELIVERY or FAILED.
RejectedThe recipient refused delivery or the driver rejected the order.
  1. Check Own van Routine first. use any active Scheduled or Failed override.
  2. Otherwise check OptimoRoute for rejected.
  3. If there is no applicable result, OW J is REJECTED.
CancelledThe order or delivery has been cancelled.
  1. Check OW method T. TO BE CANCELLED gives Cancelled.
  2. OptimoRoute cancelled has no direct Atlas mapping.
  3. If there is no applicable result, OW J is X.
ReturnThe shipment is being returned or has been returned to the sender.
  1. Check Own van Routine first. use any active Scheduled or Failed override.
  2. Otherwise check OptimoRoute for returned.
  3. If there is no applicable result, OW J is RETURN.

Palletways

Tracking statusMeaningHow Atlas decides
UnscheduledDelivery arrangements are still unconfirmed or there is insufficient information to confirm them.
  1. When the Palletways Sheet label is blank, the dropdown uses the Atlas classification.
  2. Check Palletways API for Unscheduled.
  3. If no applicable carrier result, OW J is W, K, H, I, A, U, Y, UNSCHEDULED, blank or unmapped.
UnassignedThe order is on hold and has no assigned delivery arrangement.
  1. When the Palletways Sheet label is blank, the dropdown uses the Atlas classification.
  2. Check OW method T for ON HOLD - TBC.
ScheduledThe delivery is being prepared, arranged or transported before the final delivery stage.
  1. When the Palletways Sheet label is blank, the dropdown uses the Atlas classification.
  2. Check Palletways API for In Transit or Scheduled.
  3. If no applicable carrier result, OW J is P, S or SCHEDULED.
  4. Tracking can show AT DELIVERY DEPOT or DEPARTED HUB.
DEPARTED HUBFreight has left the hub.
  1. When the Palletways Sheet supplies this label, use it in the dropdown.
  2. Atlas stores its overall classification separately.
AT DELIVERY DEPOTFreight is at the destination depot.
  1. When the Palletways Sheet supplies this label, use it in the dropdown.
  2. Atlas stores its overall classification separately.
OUT FOR DELIVERYFreight is in the final delivery stage.
  1. When the Palletways Sheet supplies this label, use it in the dropdown.
  2. Atlas stores its overall classification separately.
Out for DeliveryFinal delivery is in progress. For Own van, this also includes orders scheduled in OptimoRoute.
  1. When the Palletways Sheet label is blank, the dropdown uses the Atlas classification.
  2. Check Palletways API for Out for Delivery.
  3. If no applicable carrier result, OW J is OUT FOR DELIVERY.
DeliveredDelivery is confirmed by carrier evidence or an eligible Own van fallback.
  1. Check the Palletways API for a confirmed delivery result.
  2. Use Palletways column F for the Tracking label when available.
  3. If the API has no applicable status, check OW column J. OW Completed alone leaves delivery unconfirmed.
JOB COMPLETEThe carrier reports the job complete.
  1. Use Palletways F for the Tracking label when available.
  2. Require a confirmed Palletways delivery outcome for Atlas Delivered.
  3. If the API has no applicable result, use OW J for other applicable classifications. OW Completed leaves delivery unconfirmed.
FailedA delivery exception requires follow-up, such as an unsuccessful attempt or damage.
  1. When the Palletways Sheet label is blank, the dropdown uses the Atlas classification.
  2. Check Palletways API for Failed or Damaged.
  3. If no applicable carrier result, OW J is FAILED DELIVERY or FAILED.
RejectedThe recipient refused delivery or the driver rejected the order.
  1. When the Palletways Sheet label is blank, the dropdown uses the Atlas classification.
  2. Check Palletways API for Refused.
  3. If no applicable carrier result, OW J is REJECTED.
LostThe shipment has been reported lost.
  1. When the Palletways Sheet label is blank, the dropdown uses the Atlas classification.
  2. Check Palletways API for Lost.
CancelledThe order or delivery has been cancelled.
  1. When the Palletways Sheet label is blank, the dropdown uses the Atlas classification.
  2. Check OW method T for TO BE CANCELLED.
  3. If no applicable carrier result, OW J is X.
ReturnThe shipment is being returned or has been returned to the sender.
  1. When the Palletways Sheet label is blank, the dropdown uses the Atlas classification.
  2. Check Palletways API for Return.
  3. If no applicable carrier result, OW J is RETURN.

Amazon Shipping

Tracking statusMeaningHow Atlas decides
UnscheduledAtlas has no confirmed delivery arrangement.
  1. When there is no Amazon status label, the dropdown uses the overall Atlas classification.
  2. OW tracking S is blank, or the OW fallback gives Unscheduled.
Ready To ReceiveShipment is ready for Amazon to receive.
  1. Amazon G = READY_FOR_RECEIVE. Tracking shows Ready To Receive.
  2. Overall Atlas classification is Scheduled.
In TransitShipment is moving through the carrier network.
  1. Amazon G = IN_TRANSIT. Tracking shows In Transit.
  2. Overall Atlas classification is Scheduled.
Out For DeliveryShipment is in the final delivery stage.
  1. Amazon G = OUT_FOR_DELIVERY. Tracking shows Out For Delivery.
  2. Overall Atlas classification is Out for Delivery.
Awaiting Customer PickupShipment is awaiting customer collection.
  1. Check Amazon Shipping G for AWAITING_CUSTOMER_PICKUP and keep the Tracking label.
  2. Preserve pickup pending even without an Atlas mapping. OW Completed leaves delivery unconfirmed.
DeliveredAmazon reports successful delivery.
  1. Check Amazon Shipping column G for DELIVERED. Combine confirmed deliveries under one Delivered filter.
  2. If Amazon has no recognised status, check OW column S. Blank tracking gives Unscheduled.
  3. If tracking exists, check OW delivery method in column T, then order status in column J. OW Completed alone leaves delivery unconfirmed.
Delivery AttemptedA delivery attempt was recorded.
  1. Check Amazon Shipping column G for DELIVERY_ATTEMPTED. Show Delivery Attempted and classify as Failed.
  2. If Amazon has no recognised status, check OW column S. Blank tracking gives Unscheduled.
  3. If tracking exists, check OW delivery method in column T, then order status in column J. OW Completed alone leaves delivery unconfirmed.
UndeliverableAmazon reports that delivery could not be completed.
  1. Amazon G = UNDELIVERABLE. Tracking shows Undeliverable.
  2. Overall Atlas classification is Failed.
RejectedThe source reports a rejection.
  1. Check Amazon Shipping column G for REJECTED. Show and classify as Rejected.
  2. If Amazon has no recognised status, check OW column S. Blank tracking gives Unscheduled.
  3. If tracking exists, check OW delivery method in column T, then order status in column J. OW Completed alone leaves delivery unconfirmed.
LostAmazon reports the shipment lost.
  1. Amazon G = LOST. Tracking shows Lost.
  2. Overall Atlas classification is Failed.
Returned To SellerThe source reports a return to the seller.
  1. Amazon G = RETURNED_TO_SELLER. Tracking shows Returned To Seller.
  2. For the overall classification, check OW tracking S. Blank gives Unscheduled.
  3. With tracking present, check OW delivery method T, then OW J.

XDP

Tracking statusMeaningHow Atlas decides
AwaitingNo XDP Sheet status is available.
  1. If XDP Sheet I is blank, use the Atlas classification.
  2. Atlas classification is Awaiting.
DELIVERY / At Delivery DepotArrived at the depot responsible for final delivery.
  1. For each consignment, read XDP Activity newest first by event date and time. Skip SMS and EMAIL notifications. Match column I (Status Type) with column J (Status Data).
  2. Show the matching depot or route detail in Tracking and classify it as Scheduled.
  3. If the event does not establish progress, check the previous substantive event. Use Awaiting when no event establishes progress.
DELIVERY / Scheduled for DeliveryAssigned to a delivery route.
  1. For each consignment, read XDP Activity newest first by event date and time. Skip SMS and EMAIL notifications. Match column I (Status Type) with column J (Status Data).
  2. Show the matching depot or route detail in Tracking and classify it as Scheduled.
  3. If the event does not establish progress, check the previous substantive event. Use Awaiting when no event establishes progress.
DELIVERY / Out for Delivery or NEXT STOPFinal delivery is underway.
  1. For each consignment, read XDP Activity newest first by event date and time. Skip SMS and EMAIL notifications. Match column I (Status Type) with column J (Status Data).
  2. Out for Delivery
  3. If the event does not establish progress, check the previous substantive event. Use Awaiting when no event establishes progress.
DELIVEREDXDP recorded delivery.
  1. For each consignment, read XDP Activity newest first by event date and time. Skip SMS and EMAIL notifications. Match column I (Status Type) with column J (Status Data).
  2. Classify the order as Delivered once all consignments are delivered. For partial delivery, retain the progress of the remaining consignments.
  3. If the event does not establish progress, check the previous substantive event. Use Awaiting when no event establishes progress.
DamageThe Sheet records damage.
  1. Use the XDP Sheet I label when present.
  2. Atlas classification is Failed.
Not ReceivedThe Sheet records non-receipt.
  1. Use the XDP Sheet I label when present.
  2. Atlas classification is Failed.
EXCEPTIONCheck the carrier's event details.
  1. For each consignment, read XDP Activity newest first by event date and time. Skip SMS and EMAIL notifications. Match column I (Status Type) with column J (Status Data).
  2. Service Fail gives Failed. Check Address flags an address review. Carded shows a delivery attempt. Update from later substantive events.
  3. If the event does not establish progress, check the previous substantive event. Use Awaiting when no event establishes progress.
MISROUTEA piece was routed to the wrong depot.
  1. For each consignment, read XDP Activity newest first by event date and time. Skip SMS and EMAIL notifications. Match column I (Status Type) with column J (Status Data).
  2. Show the routing exception and wait for a later scan before changing the delivery outcome.
  3. If the event does not establish progress, check the previous substantive event. Use Awaiting when no event establishes progress.
DeleteThe Sheet records a deletion.
  1. Use the XDP Sheet I label when present.
  2. Atlas classification is Failed.
EditThe Sheet records an edit.
  1. Use the XDP Sheet I label when present.
  2. Atlas classification is Awaiting.
EmailThe Sheet records an email.
  1. Use the XDP Sheet I label when present.
  2. Atlas classification is Awaiting.
Irish ManifestThe Sheet records an Irish manifest event.
  1. Use the XDP Sheet I label when present.
  2. Atlas classification is Awaiting.
SMSThe Sheet records an SMS event.
  1. Use the XDP Sheet I label when present.
  2. Atlas classification is Awaiting.

StopStart

Tracking statusMeaningHow Atlas decides
Tracking UnavailableNo carrier tracking information is available.
  1. Check STOPSTART A for the order and I for the tracking label.
  2. Use OW J for other applicable classifications. OW Completed leaves delivery unconfirmed.
Expected TodayThe source expects delivery today. This label qualifies for the Today filter, subject to its exclusions.
  1. Check STOPSTART A and I. Apply the Today filter exclusions.
  2. Use OW J for other applicable classifications. OW Completed leaves delivery unconfirmed.
UnscheduledDelivery arrangements are unconfirmed.
  1. Match the order in STOPSTART column A and check column I for a carrier result.
  2. If no applicable carrier result is available, check OW column J. Show Unscheduled when OW maps to Unscheduled.
DeliveredStopStart tracking reports delivery.
  1. Match the order in STOPSTART column A and read the tracking result in column I. Update the existing record when the source changes.
  2. Classify as Delivered when column I reports Delivered. Past Expected Date — Unconfirmed leaves delivery unconfirmed.
  3. If column I is blank or tracking is unavailable, use OW column J for other applicable classifications. OW Completed alone leaves delivery unconfirmed.
Past Expected Date — UnconfirmedThe expected delivery date has passed without delivery confirmation.
  1. Check STOPSTART A and I. Keep delivery unconfirmed.
  2. Use OW J for other applicable classifications. Update the same order if STOPSTART later reports Delivered.

Atlas Status Meanings

Unscheduled
Delivery arrangements are still unconfirmed or there is insufficient information to confirm them.
Scheduled
The delivery is being prepared, arranged or transported before the final delivery stage.
Out for Delivery
Final delivery is in progress. For Own van, this also includes orders scheduled in OptimoRoute.
Delivered
Atlas classifies the delivery as complete based on carrier evidence or its current OW fallback rules.
Failed
A delivery exception requires follow-up, such as an unsuccessful attempt or damage.
Rejected
The recipient refused delivery or the driver rejected the order.
Lost
The shipment has been reported lost.
Cancelled
The order or delivery has been cancelled.
Return
The shipment is being returned or has been returned to the sender.
Unassigned
The order is on hold and has no assigned delivery arrangement.
Awaiting
The default Atlas classification for XDP orders. The Tracking label shows the available progress.
